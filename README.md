# ZTG

**ZTG** — десктопное приложение для подключения Telegram через локальный MTProto-прокси.

Программа запускает локальный прокси-сервер на компьютере пользователя и помогает быстро подключить его в Telegram Desktop. После запуска достаточно нажать кнопку подключения, затем открыть Telegram через приложение — настройки прокси будут переданы автоматически.

## Возможности

- локальный MTProto-прокси для Telegram;
- быстрый запуск и подключение через Telegram Desktop;
- современный интерфейс на русском языке;
- отдельные окна «Настройки» и «Инструкция»;
- поддержка резервных вариантов подключения;
- версии для Windows и macOS.

## Как использовать

1. Скачайте версию для своей операционной системы.
2. Запустите приложение **ZTG**.
3. Нажмите **«Подключить»**.
4. Нажмите **«Открыть в Telegram»**.
5. Подтвердите подключение прокси в Telegram Desktop.
